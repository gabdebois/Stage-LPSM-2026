\section*{Cohérence de l'ansatz de mise à l'échelle pour $\Pi^-$}

Nous souhaitons vérifier que l'ansatz défini par l'équation (55) :
$$
\Pi_\beta = \mu^{[\beta]+1} \hat{\Pi}_\beta, \quad c_k = \mu^{2k} \hat{c}_k
$$
est compatible avec la définition de la composante $\Pi^-_\beta$ donnée par l'équation (49), conduisant ainsi à la relation :

$$\Pi^-_\beta = \mu^{[\beta]+1} \hat{\Pi}^-_\beta
$$

L'homogénéité du bruit $[\beta]$ est définie par (53) comme $[\beta] := 2\beta(3) - \sum_{\mathbf{n}} \beta(\mathbf{n})$. On note que $[\cdot]$ est additif par rapport au multi-indice $\beta$.

\subsection*{1. Le terme de bruit ($\beta = 0$)}
D'après (49), pour $\beta=0$, on a $\Pi^-_0 = \xi_\rho$. Par définition (53), $ = 0$. 
En utilisant la transformation de l'intensité du bruit $\xi = \mu \hat{\xi}$ issue de (54), nous obtenons :

$$\Pi^-_0 = \mu \hat{\xi}_\rho = \mu^{0+1} \hat{\Pi}^-_0 = \mu^{[\beta]+1} \hat{\Pi}^-_0$$

La relation est donc vérifiée pour le terme initial.

\subsection*{2. Le terme cubique (interaction)}

Le premier terme de la somme dans (49) fait intervenir des produits de la forme $\Pi_{\beta_1}\Pi_{\beta_2}\Pi_{\beta_3}$ sous la contrainte $\delta_3 + \beta_1 + \beta_2 + \beta_3 = \beta$. 
En appliquant l'ansatz de mise à l'échelle, ce produit devient :

$$(\mu^{[\beta_1]+1} \hat{\Pi}_{\beta_1}) (\mu^{[\beta_2]+1} \hat{\Pi}_{\beta_2}) (\mu^{[\beta_3]+1} \hat{\Pi}_{\beta_3}) = \mu^{[\beta_1] + [\beta_2] + [\beta_3] + 3} (\hat{\Pi}_{\beta_1}\hat{\Pi}_{\beta_2}\hat{\Pi}_{\beta_3})$$
L'homogénéité de $\delta_3$ est $[\delta_3] = 2(1) - 0 = 2$. Par additivité de $[\cdot]$, la contrainte sur les indices implique :

$$[\beta] = [\delta_3] + [\beta_1] + [\beta_2] + [\beta_3] = 2 + [\beta_1] + [\beta_2] + [\beta_3]$$

L'exposant de $\mu$ dans le produit est donc :

$$[\beta_1] + [\beta_2] + [\beta_3] + 3 = ([\beta] - 2) + 3 = [\beta] + 1$$

Ce terme respecte donc la puissance de $\mu$ attendue.

\subsection*{3. Le terme de contre-réaction (renormalisation)}
Le second terme de la somme dans (49) est de la forme $c_{\beta_1} \Pi_{\beta_2}$ avec $\beta_1 + \beta_2 = \beta$, où $\beta_1$ est un indice de la forme $k\delta_3$ (lié uniquement à $\lambda$). 
Pour cet indice, on a $c_{\beta_1} = c_k$ et $[\beta_1] = [k\delta_3] = 2k$. En appliquant l'ansatz, le produit se transforme en :

$$(\mu^{2k} \hat{c}_k) (\mu^{[\beta_2]+1} \hat{\Pi}_{\beta_2}) = \mu^{2k + [\beta_2] + 1} (\hat{c}_k \hat{\Pi}_{\beta_2})$$

Par additivité, $[\beta] = [\beta_1] + [\beta_2] = 2k + [\beta_2]$. L'exposant de $\mu$ est alors :

$$2k + [\beta_2] + 1 = [\beta_1] + [\beta_2] + 1 = [\beta] + 1$$


\subsection*{Conclusion}
Chaque terme du membre de droite de l'équation (49) se transforme avec le même facteur $\mu^{[\beta]+1}$ [1]. L'équation est donc structurellement compatible avec l'ansatz de mise à l'échelle.
